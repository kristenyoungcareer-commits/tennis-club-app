# 테니스 클럽 운영 앱 (초기 프로토타입)

기획서: https://app.notion.com/p/1405d031b22a8306970401c1616d88c0

## 실행 방법

1. 이 폴더를 새 프로젝트로 엽니다.
2. 터미널에서 `npm install` 후 `npm start`를 실행합니다.
3. Expo Go 앱의 QR 코드 또는 iOS/Android 시뮬레이터로 확인합니다.

브라우저에서 확인하려면 `npm run web`을 실행한 뒤 터미널에 표시되는 로컬 주소를 엽니다. 홈·일정·게시판·회비·대회 탭을 이동하며 샘플 화면을 확인할 수 있습니다.

타입 검사는 `npm run typecheck`로 실행합니다.

기본 포트가 사용 중이면 `npm run web -- --localhost --port 8082`로 다른 포트를 지정할 수 있습니다.

## 현재 구현

홈, 일정(정기/추가 대관), ACTIVE 회원 참석 응답, 실제 출석 이력과 출석률, 공지/경조사/자유게시판 구분, 월별 회비, 월례대회 로테이션 복식 화면을 제공합니다. 월례대회는 기존 일정 연결, 운영진 참가자 확정, 조당 최대 8명, 개인별 목표 경기 수, 자동 대진 생성, 점수·승패·득실차·순위, 대진 공개, 결과 확정·확정 취소, 대회 취소·복구 상태를 메모리에서 시험할 수 있습니다. 대진 재생성 시 점수가 입력된 완료 경기는 보존합니다.

상단 `회원/운영진` 전환은 화면 흐름 확인용입니다. 실제 인증·서버 권한 검증이 아니며 데이터는 앱 재시작 시 초기화됩니다.
